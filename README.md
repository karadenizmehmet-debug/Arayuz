# Genel Arayüz

Okul sistemleri, ders içerikleri ve kişisel uygulamalara tek yerden giriş sayfası.

- Tek dosya: `index.html` (derleme yok)
- Yeni proje eklemek için `index.html` içindeki `items` dizisine bir satır ekle
- Sürüm: `index.html` içindeki `VERSION` değeri başlığın yanında görünür; her değişiklikte artır
- Yayın: GitHub Pages, `main` dalı, kök klasör
